# 🌦️ Weather-web

![CSS](https://img.shields.io/badge/style-CSS-blue?logo=css3) ![HTML](https://img.shields.io/badge/markup-HTML-orange?logo=html5) ![JavaScript](https://img.shields.io/badge/script-JavaScript-yellow?logo=javascript)  
**A beautiful, responsive weather app that brings the forecast to your fingertips.**

---

## ✨ Features

- **Live Weather Data** – Get real-time weather updates for any city  
- **Responsive Design** – Looks great on phones, tablets, and desktops  
- **User-Friendly UI** – Minimal, modern, and easy to use  
- **Animated Weather Icons** – Visually engaging forecasts  
- **Dark Mode** – Save your eyes, day or night  
- **Search History** – Quickly revisit previously searched cities

## 🛠️ Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/satoshii-ace/Weather-web.git
cd Weather-web
```

### 2. Open in your browser

Just open `index.html` in your favorite browser.

---

## ⚙️ Configuration

- Update the API key in `config.js` (if using a weather API)
- No backend required – everything runs client-side!
